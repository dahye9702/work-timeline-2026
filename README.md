# 2026 업무 타임라인

브라우저의 `localStorage`에 업무 일정을 저장하는 단일 페이지 게시판입니다.

## 기능

- 2026년 고정 달력에서 날짜와 시간을 선택해 업무 등록
- 업무 구분(대주제) 생성, 색상 지정, 폴더별 보기
- 기존 업무의 분류·시간·내용 수정 및 삭제
- 새로고침 후에도 같은 브라우저에서 데이터 유지

## 로컬에서 열기

`실습1` 파일을 브라우저에서 열거나, 로컬 웹 서버를 실행해 확인할 수 있습니다.

## 보안

이 프로젝트에는 비밀번호, API 키, 토큰, 개인 키를 저장하지 않습니다. 이러한 값은 GitHub에 올리지 말고 `.env` 등 로컬 환경 파일에만 보관하세요.
